## 🚀 Getting Started

Welcome to lite! This application helps you manage multiple AI coding assistants from one place. You can use Claude Code, Codex, Kimi Code, DeepSeek, and your regular terminal all in one window.

### What is lite?

lite is a desktop application that brings together different AI coding tools into a single workspace. Instead of opening separate windows for each AI assistant, you can access them all from lite. It runs locally on your computer, so your data stays private.

### Who is this for?

This application is designed for:
- Developers who want to compare AI coding assistants
- Anyone curious about using AI for programming
- People who want a local, private AI workspace
- Users who want to switch between different AI tools easily

## 📖 How to Use lite

### Opening the Application
After installation, double-click the lite icon to start the application. You will see a clean interface with a sidebar and a main content area.

### Adding an AI Assistant
1. Click the "+" button in the sidebar
2. Select an AI assistant from the list (Claude Code, Codex, Kimi Code, DeepSeek)
3. Configure any necessary settings (API keys may be required for some assistants)
4. Click "Add" to include the assistant in your workspace

### Using the Terminal
Click on the terminal tab at the bottom of the window. Type commands just like you would in Command Prompt or Terminal. The terminal supports common shell operations.

### Switching Between Assistants
Click on any assistant name in the sidebar to activate it. Your conversation history is preserved for each assistant.

## 🛠️ Troubleshooting

**Application won't start:**
- Make sure your computer meets the system requirements
- Try reinstalling the application
- Check if your antivirus software is blocking the application

**AI assistant not responding:**
- Ensure you have a stable internet connection
- Check that your API keys are correct (if required)
- Restart the application

**Terminal not working:**
- Make sure your shell is properly installed on your system
- Try resetting the terminal from settings
